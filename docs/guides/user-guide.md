## Welcome

Welcome to the Bangkok Shambhala website! We're a non-profit meditation community based in the heart of Bangkok, offering regular meditation sessions, workshops, and retreats for people of all experience levels.

This guide will help you navigate the website and make the most of what our community has to offer.

**Website:** `https://shambhala-bangkok.org`

---

## 1. Finding Events

### 1.1 Browsing Upcoming Events

1. Visit the website homepage or click **Events** in the navigation menu
2. You'll see a list of **upcoming events** sorted by date
3. Each event card shows:
   - **Title** — name of the session
   - **Date & time** — in Bangkok timezone (GMT+7)
   - **Modality badge** — In-person, Online, or Hybrid
   - **Pricing badge** — Free, By donation, or Paid
   - **Short summary** — what the event is about

4. Click on any event card to see the full details

### 1.2 Event Detail Page

On the event detail page you'll find:

- **Full description** of the event
- **Date, time, and duration**
- **Location** (with map link for in-person events)
- **Facilitator** information
- **Registration link** (if required)
- **Add to Calendar** button

### 1.3 Event Types

| Type              | Description                      | Typical Schedule     |
| ----------------- | -------------------------------- | -------------------- |
| Weekly Meditation | Open sitting meditation practice | Wed 19:00, Sun 10:00 |
| Workshop          | Themed session with instruction  | Monthly, Saturdays   |
| Retreat           | Multi-day intensive practice     | Quarterly            |
| Online Session    | Virtual meditation via Zoom      | Various times        |
| Special Event     | Guest teachers, celebrations     | As announced         |

### 1.4 Past Events

Scroll down on the Events page to find the **Past Events** section. This is useful for:

- Seeing what kinds of events we offer
- Finding recap information or resources from past workshops

## 2. Adding Events to Your Calendar

### 2.1 Add a Single Event

On any event detail page:

1. Click the **Add to Calendar** button
2. Choose your calendar:
   - **Google Calendar** — opens Google Calendar with the event pre-filled
   - **Download ICS** — downloads a calendar file you can open in Apple Calendar, Outlook, or any other calendar app

### 2.2 Subscribe to All Events

Never miss an event by subscribing to our calendar feed:

1. Copy this URL: `https://shambhala-bangkok.org/api/calendar/feed.ics`
2. In your calendar app:

**Google Calendar:**

- Open Google Calendar → Settings (gear icon)
- Click "Add calendar" → "From URL"
- Paste the URL and click "Add calendar"

**Apple Calendar (iPhone/Mac):**

- Go to Settings → Calendar → Accounts → Add Account
- Choose "Other" → "Add Subscribed Calendar"
- Paste the URL

**Outlook:**

- Open Outlook Calendar → Add calendar → Subscribe from web
- Paste the URL

> **Tip:** Calendar subscriptions update automatically, so new events appear without any extra action.

### 3.1 Community Channels

We use messaging groups to stay connected between events:

| Channel            | Purpose                                | How to Join                                     |
| ------------------ | -------------------------------------- | ----------------------------------------------- |
| **WhatsApp Group** | Main community chat, event updates     | Click the WhatsApp button on the Community page |

| **Facebook**       | Event photos, articles, public updates | Follow our Facebook page                        |
| **Instagram**      | Visual updates, meditation quotes      | Follow @shambhalabangkok                        |

### 3.2 Joining WhatsApp or LINE

1. Visit `https://shambhala-bangkok.org/community`
2. Click the **Join WhatsApp** or **Join LINE** button
3. You'll be redirected to the group invite link
4. Tap "Join Group" in WhatsApp/LINE

> **Note:** These are community groups — please be respectful and follow our Code of Conduct.

### 3.3 Newsletter

Stay updated via email:

1. Find the **newsletter signup** in the website footer (bottom of any page)
2. Enter your email address
3. Click **Subscribe**
4. You'll receive:
   - Weekly event reminders
   - Monthly community news
   - Special event announcements

To unsubscribe, click the "Unsubscribe" link at the bottom of any email.

The website is designed to be accessible to everyone:
